# BBQ Maze 🍔🍖

BBQ Maze is a modern, responsive Single Page Application (SPA) built using **React** and **Material UI (MUI)**. It allows users to explore various food categories like Desi Food, Fast Food, and Sweets, view item details, and place orders.

![BBQ Maze Preview](public/bbq.avif)

## 🚀 Features

- **Responsive Design**: Clean and fully responsive layout for Mobile, Tablet, and Desktop screens.
- **Category Filtering**: Easily filter items between *All*, *Desi Food*, *Fast Food*, and *Sweets*.
- **Modern UI**: Styled with Material UI (MUI) components, featuring custom hover animations, badges, and sleek cards.
- **Fast Performance**: Powered by Vite and React for ultra-fast load times.

## 🛠️ Tech Stack

- **Frontend**: React.js
- **UI Framework**: Material UI (MUI v5/v6) & `@mui/icons-material`
- **Build Tool**: Vite
- **Styling**: Emotion (`@emotion/react`, `@emotion/styled`) & MUI System

## ⚙️ Getting Started

### Prerequisites

Make sure you have Node.js installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/bbq-maze.git
   ```

2. Navigate into the project directory:
   ```bash
   cd bbq-maze
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
